# Affinity Answers Take-Home Assignment

This repository contains my solutions for the Affinity Answers recruitment assessment.

---

## 📂 Folder Overview

### 1️⃣ task1_olx_scraper/
Python script to scrape OLX search results for "Car Cover" — extracts **title**, **description**, and **price** and prints in table format.

### 2️⃣ task2_rfam_queries/
SQL queries for the Rfam public database questions — includes queries for tiger taxonomy, table relationships, longest rice DNA sequence, and pagination.

### 3️⃣ task3_nav_extract/
Shell script to extract "Scheme Name" and "Asset Value" from AMFI NAVAll.txt and save them in TSV format. Also includes optional Python converter to JSON.
